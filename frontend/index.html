Break it on purpose. Then test it.

Every alt is a way your system fails: watch the packet die at the database, not in production. Then check requirements, traffic and capacity in your browser. Green means it holds up.

Break it

usecase "Pay" {
  web -> api : POST /pay

  alt "Paid" {
    api  -> db  : INSERT payment
    api --> web : 201
  } alt "DB down" {
    api  -x db  : INSERT payment
    api --> web : 503 {"error": "retry_later"}
  }
}

Test it

traffic {
  "Redirect" 100k rps mix "Cache hit" 90%, "Cache miss" 9%, "Unknown code" 1%
}

requirements {
  p99 "Redirect" < 100ms
  availability "Redirect" >= 99.95%
  survive any node failure
  cost <= 5000 usd/month
}
